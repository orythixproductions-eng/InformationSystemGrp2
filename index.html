CORE CONCEPT

Information
System

An Information System is a collection of people, hardware, software, data, and procedures that work together to collect, process, store, and distribute information.

SIMPLE EXPLANATION

Think of an information system as a complete system that takes data as input, processes it using technology and procedures, and produces useful information for people.

RAW FACTS

Data

Data consists of raw facts such as numbers, names, dates, grades, prices, images, and observations.

DATA FLOW

Data may be entered by users, collected automatically, or imported from other systems. It is stored so that it can later be processed into useful information.

SYSTEM CLASSIFICATION

Types of Information Systems

TPS

Transaction Processing System

Handles routine transactions such as purchases and payments.

MIS

Management Information System

Produces reports that help managers monitor operations.

DSS

Decision Support System

Supports analysis and complex decision-making.

EIS

Executive Information System

Provides high-level information to executives.

ERP

Enterprise Resource Planning

Integrates major business functions into one system.
